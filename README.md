## Sobre mim

Estudante de **Segurança da Informação**, desenvolvendo soluções com **Python e SQL** para automatizar tarefas, analisar dados e identificar comportamentos suspeitos.

Meu portfólio registra uma evolução prática: leitura e correlação de logs, detecção de força bruta, persistência em JSON, testes automatizados e modelagem de dados para investigação de incidentes.

> **Objetivo atual:** transformar conhecimento técnico em soluções claras, testáveis e bem documentadas.
